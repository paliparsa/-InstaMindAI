Both integrations use Google Gemini, but their API keys and model IDs are stored separately in this browser's extension storage and are never included in exports.

Image analysis (optional)

When configured, each profile review randomly samples up to 2 post thumbnails currently visible on that profile and sends them to this separate Gemini Vision model. This is used only to identify clearly explicit content, not to identify people or infer personal traits.

Privacy

No Instagram password, cookies, DMs or private data are collected. On review, visible profile text and up to two randomly sampled visible post thumbnails may be sent to Google Gemini only after explicit consent. The text and image API keys are separate. Consent is requested again after this update. Gender and other sensitive traits are never inferred from photos, names or faces. No likes, follows, messages or unfollows are performed.
